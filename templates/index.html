What is GotFish?

GotFish is a phishing detection analyzer built for identifying malicious links and emails. Attackers often disguise their infrastructure using deceptive tricks — and GotFish shines a light on them.

GotFish Detection Logic:

  • Punycode Domain Handling: Detects domains starting with xn--, which can hide non-ASCII characters inside URLs.
  • Typo Squatting (Similarity Analysis) Compares domains to trusted brands (Google, Microsoft, PayPal, etc.) using string similarity scoring to catch typosquatting.
  • Suspicious Pattern Scans: Looks for risky structures like @ inside domains (possible redirects) or repeated dashes often used in fake domains.
  • Character Spell-Out Mode: Every character in the input is spelled out and shown with its Unicode code point, so users can see exactly what’s in front of them — no more hidden tricks.
  • Foreign Character Alerts: Warns you if a domain or email contains letters outside the standard Latin alphabet.

Why It Matters

Phishing campaigns rely on visual deception. GotFish turns these tricks into something obvious and undeniable, helping both defenders and everyday users recognize:

  • Credential harvesting attempts
  • Malicious email senders
  • Typosquatted domains
  • Unicode/IDN homograph attacks

By combining automated detection with human-readable analysis, GotFish bridges the gap between technical defenses and user awareness — making phishing tricks easier to spot and harder to fall for.
